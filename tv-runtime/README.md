# Snapshot from LG TV

This directory mirrors the deployed application and exported Homebrew hooks.
`app/` corresponds to `/media/developer/apps/usr/palm/applications/org.webosbrew.lounge.launcher/`.
`init.d/` corresponds to `/var/lib/webosbrew/init.d/` (only the three Launch Home hooks exported).
Runtime backups, bytecode, and the nested archive are excluded.
This snapshot is **not** a replacement for the repository build system.
